# EverProxy —— 零依赖短效代理无缝轮换工具

**EverProxy** 是一个基于 Python 标准库构建的轻量级代理轮换工具，专为解决短效 IP 代理生命周期短、频繁断连的问题而设计。它能将不稳定的短效代理 API 转换成本地稳定的长效代理服务，让你的业务无感使用不断线的上游代理。

---

## ✨ 核心特性

* **🚀 零第三方依赖**：仅使用 Python 标准库，无需 `pip install` 任何第三方包，开箱即用。
* **🔗 双向多协议自适应**：
  * **本地服务**：自动识别并兼容 HTTP、HTTPS 与 SOCKS5 客户端请求。
  * **上游代理**：支持 auto / http / https / socks5，自动匹配协议。
* **⚡ 预备池与无缝切换**：后台独立线程预取并验证候选代理到预备池中，切 IP 时秒级就绪，用户连接零中断。
* **💓 心跳监控与智能重试**：持续通过心跳检测代理活性，遇死连或超过设定的生存周期后自动无缝轮换。
* **📊 灵活的数据解析**：支持 TXT（自定义分隔符）及复杂的 JSON 格式 API 返回数据。
* **🌍 IP 测速与归属地查询**：可选多线程并发测速（选用最快 IP）及展示 IP 地理位置信息。
* **🌐 双语日志支持**：支持中文（`cn`）和英文（`en`）双语日志输出。

## 🚀 快速开始

### 1. 下载项目
将 `proxy.py` 与 `config.ini` 放于同一目录下。

### 2. 配置 API 地址
打开 `config.ini`，将你从代理服务商处获得的 API 链接填入 `api_url`：

```ini
[proxy]
api_url = https://your-proxy-provider.com/api?num=10
```

### 3. 运行程序

```bash
python proxy.py [config.ini 路径]
```

> 提示：不传参数时，默认读取同目录下的 `config.ini`。

### 4. 使用本地代理

启动成功后，在需要使用代理的软件中填写本地监听地址即可：

* **代理地址**：`127.0.0.1:1217`（默认端口为 `1217`，同时兼容 HTTP / SOCKS5）

## ⚙️ 常见配置项说明 (`config.ini`)

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `api_url` | *(空)* | **必填**，代理提取 API URL |
| `input_protocol` | `auto` | 上游协议：`auto` / `http` / `https` / `socks5` |
| `output_protocol` | `same` | 本地协议：`same` / `http` / `https` / `socks5` |
| `force_change_interval` | `60` | 强制更新 IP 间隔周期（秒） |
| `heartbeat_interval` | `10` | 心跳包检测频率（秒），失效即换 |
| `multithread_test` | `false` | 是否多线程并发测试并选择最快 IP |
| `standby_pool_size` | `2` | 预备池大小，为 `0` 时禁用无缝切换备胎功能 |
| `show_location` | `true` | 是否显示当前代理 IP 的地理位置 |
| `language` | `cn` | 日志语言：`cn` / `en` |
| `listen_port` | `1217` | 本地代理服务的监听端口 |
| `max_retries` | `10` | 连续失败重试上限，`0` 表示无限重试 |

## 🔧 工作流程

1. **自动提取**：按计划从配置的 API 地址抓取一批短效代理候选 IP。

2. **格式解析**：按配置自动解析 TXT 文本或复杂 JSON 中的 `ip:port` 列表。

3. **测速优选**：根据单线程或多线程设定，测试上游可用性及响应延迟。

4. **长效中转**：在本地 `127.0.0.1:1217` 监听请求，实时透明转发全部流量。

5. **无缝迭代**：在原代理到期或心跳断线时，通过预备池新 IP 无闪断完成上线更换。
